# pagina-robot (repo 2: la página)

Página estática (HTML/CSS/JS). Se publica con GitHub Pages.

1. Sube esta carpeta a un repo de GitHub (los archivos en la raíz, junto a `index.html`).
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `/ (root)`.
3. Abre la página, baja a **CONFIGURACIÓN DE LA API** y escribe:
   - URL: `https://TU-API.onrender.com/api`   (termina en `/api`)
   - Clave: la misma `API_KEY` del servidor
   y pulsa **GUARDAR Y CONECTAR**. Se guarda solo en tu navegador, no en el repo.
